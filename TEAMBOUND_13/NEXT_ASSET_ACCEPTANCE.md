# Next acceptance gate

1. Install the prepared actual rescuer in the game on a real desktop browser, save offline, reopen and record third-person walking, crouch, every-direction grip, mantle, hanging/release, falling/recovery, carrying, and first-person camera sweeps.
2. Inspect wrist/palm alignment, sleeve twisting, shoulder armpit collapse, elbow/knee volume and boot contact. Record residuals on actual mesh vertices, not only joint targets.
3. Test the same embedded model for four browser clients, including shared body, raft and dive. Verify each client loaded the same asset SHA and that visual selection did not affect authority.
4. Replace firefighter clothing with an original alpine expedition outfit, without changing identity, joint mapping, or collision dimensions. Author cloth/correctives and real motion data as separate accepted assets; do not rename procedural cycles as mocap.
5. Bring a small production terrain/contact section to the same art standard. Validate actual game frames, not a photographic skybox or offline promotional render.
