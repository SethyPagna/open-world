## Machine quirks (important)
- **Session limits and transient `API Error: 403`s have killed workflows several times.** Wrap agent calls in the retry helper (`run()` in `_design/workflows/master_design_unity_v2.js`) and save results to disk. `resumeFromRunId` works within the same session only.
- **Unity is slow and single-instance.** A cold batchmode run takes 4–8 minutes, and Unity sometimes crashes (0xC0000005) on shutdown after finishing its work; the gate ignores that crash. So writers should use `check`/`core` and batch the Unity runs.
- **Shell pitfalls.** `npx` hangs. Heredocs through the Bash tool can mangle backslashes and quotes, so write files with the Write tool.
- **Unity Hub is MSIX.** Installs into Program Files need the user to approve a UAC prompt.
